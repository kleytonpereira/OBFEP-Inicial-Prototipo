Acessibilidade desta versão

Esta é uma versão corrigida, para pesquisa, da página oficial (Olimpíada Brasileira de Física das Escolas Públicas). Não é o site oficial e não é atualizada.

Meta

Critérios de nível A e AA das Diretrizes de Acessibilidade para Conteúdo Web (WCAG) 2.2 e art. 63 da Lei Brasileira de Inclusão, mantendo o visual original.

Correções aplicadas

  • scripts do original removidos (11); links e recursos relativos tornados absolutos
  • viewport sem bloqueio de zoom
  • link "Ir para o conteúdo" como primeiro elemento
  • título vazio do cabeçalho removido (1×)
  • menu identificado como navegação (1×)
  • cabeçalho identificado como região (1×)
  • rodapé identificado como região (1×)
  • campo de busca com rótulo (1×)
  • itens de menu sem destino deixam de ser links falsos (submenus abrem ao receber foco) (7×)
  • links para .doc/.docx indicam o formato (2×)
  • título da página identifica que é a página inicial (1×)
  • conteúdo dentro de <main>, com h1 (visualmente oculto: o original não tem título visível) (1×)
  • fim do <main> (1×)
  • banner "Pontuação para a 2° Fase da OBFEP 2026" (texto só na imagem) com texto alternativo (1×)
  • banner "OBFEP 2026 – Concurso de Ilustrações" (texto só na imagem) com texto alternativo (1×)
  • banner "Seja Bem-vindo à Olimpíada Brasileira de Física das Escolas Públicas" (texto só na imagem) com texto alternativo (1×)
  • banner "Programa da OBFEP 2026" (texto só na imagem) com texto alternativo (1×)
  • banner "Calendário da OBFEP 2026" (texto só na imagem) com texto alternativo (1×)
  • imagens dos cartões deixam de ser um segundo link para o mesmo destino (decorativas; o título já é o link) (6×)
  • moldura decorativa dos cartões com alt vazio (3×)
  • títulos dos posts de h2 para h3 (abaixo de "Últimas Novidades") (3×)
  • títulos de "Multimídia" de h2 para h3 (3×)
  • fechamentos de tag sem abertura removidos, herdados do original (1×; HTML válido)
  • símbolo e página de acessibilidade, link para o original e aviso no rodapé

Avaliação

A verificação é feita com ASES, WAVE e Lighthouse e por inspeção manual (UFC Quixadá, 2026).
